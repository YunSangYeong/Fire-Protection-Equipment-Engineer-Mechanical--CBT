## 검토 내용과 한계

- 생성기는 Python Decimal로 계산하고 소수 둘째 자리까지 ROUND_HALF_UP을 적용합니다. 별도 TypeScript 테스트는 SI 단위 공식으로 모든 계산형 920개를 다시 계산하고 반올림·정답 번호·유일한 동치 보기·단위를 확인합니다.
- 문항마다 이상기체, 정상 층류, 상사법칙, 무손실, 균일 분포 등 적용 가정을 표시했습니다. 노즐 계수·혼합비 등은 문제에서 가정한 값이며 법정 설치·소화약제 설계 기준이 아닙니다.
- 자체 작성 과정에서 식·단위·문장·보기의 내부 AI 검토를 수행했습니다. 외부 전문가 검수·현재 법령과 공식 출제기준 대조·실제 시험 난이도 검증은 하지 않았습니다. `reviewed`는 이 내부 검토 상태입니다.
- 법규는 기존 일반 법규 독해 기초 20개를 보존했습니다. 공식 소방 법령 수치 문항을 확인 없이 추가하지 않았습니다. 과목별 문항 수는 260/360/20/360이며 균등 은행이나 공식 출제범위 전체 재현이 아닙니다.
- sourceUrl은 작성 저장소이며 외부 정답 근거가 아닙니다. 읽지 않은 교재·공식 문헌을 인용하지 않았습니다. 자체 데이터는 CC BY 4.0으로 기존 고지를 유지합니다.
- 기본 문제은행 수량은 1,000개, 수량 부족은 0개입니다. 수량 충족이 위 미완료 검수를 대신하지 않습니다.

## 재현

저장소 루트에서 `python3 scripts/generate_bank.py`, `npm test`, `npm run build`를 실행합니다. 재생성 전후 바이트 동일성 검사가 있습니다. 기본 문항의 추가는 사용자 localStorage namespace·기존 ID를 바꾸지 않아 이전 기록을 참조할 수 있습니다.
